# Related Work 通用写作大纲

## 使用范围

用于相关工作的提纲、起草、扩写、精炼和结构调整。适用于不同研究方向，不固定为射频信号、开集识别、联邦学习或某种理论。

当前用户要求、材料中的真实内容与期刊要求优先于本大纲。本文件优先于 section-playbook.md 和 section-blueprints.md 中的相关工作段落模板。语言、引用和协作偏好统一见 [user-style-profile.md](user-style-profile.md)。

## 与摘要、引言的分工

三个部分围绕同一研究问题展开，但各自提供不同信息。

| 部分 | 核心任务 | 展开程度 |
|---|---|---|
| Abstract | 讲清任务、问题、方法和结果 | 用一段话保留完整逻辑，省去文献综述和实现细节 |
| Introduction | 解释为什么研究该问题，以及为什么需要相应设计 | 从实际场景进入技术原因，再引出方法 |
| Related Work | 梳理已有研究怎样处理相关问题，以及本文与这些工作的关系 | 展开处理思路、适用条件和方法之间的联系 |

引言选少量代表性工作建立问题，相关工作进一步展开技术脉络。沿用摘要和引言已经确定的任务、术语和场景，增加信息而不重复整段论述。摘要与引言的段落功能见 [abstract-introduction-outline.md](abstract-introduction-outline.md)。

## 整体结构

默认一个简短总述，加三个主题小节。主题数量和名称由当前论文决定，不能机械地为每个模块安排一个综述小节。

总述通常一句话，说明从哪几个方面回顾研究，以及各方面分别涉及什么问题。

主题可围绕研究任务、关键技术和目标场景划分，也可围绕三个相互关联的问题划分。小节之间应有清楚的范围，各自覆盖理解本文所需的一部分研究。

每个小节默认写成一个连续自然段，覆盖程度和篇幅大致均衡。文献基础或用户要求不同时可以调整，不为保持长度而填充无关工作。

## 小节内部的句子功能

默认约六至十句，按相关文献数量和论述复杂度调整，不把句数或论文数量作为配额。

| 位置 | 句子功能 |
|---|---|
| 开头一句 | 说明该方向主要处理什么问题，并给出本段的组织线索 |
| 前部两三句 | 介绍代表性的基本处理思路，交代具体操作及其解决的问题 |
| 中间一句 | 引出另一项实际约束或需要处理的因素，使后面的研究自然出现 |
| 后部两三句 | 介绍围绕这些约束发展的研究，体现处理思路的变化 |
| 最后一句 | 回到本文目标场景，明确仍需要关注的具体能力 |

可以采用以下递进关系。

- 已有能力 → 应用条件变化 → 针对性改进 → 本文关注的进一步需求。
- 基本处理方式 → 更直接的机制约束 → 更复杂条件下的适配 → 本文研究位置。

递进来自问题、条件或机制之间的联系。发表时间更晚不等于技术更先进，相邻文献也不一定存在直接继承关系。只有材料支持时才写某工作改进或解决了另一工作的不足。

一个小节内部保持主题范围。例如，当前稿件的联邦表征学习小节讨论知识汇聚、更新协调和表征复用，开集拒识文献在对应任务小节展开。这只是范围划分示例，不能把这些主题固化到其他论文。

## 单篇文献的介绍

通常一篇工作用一句话，交代所处理的问题、具体操作及其作用。关系紧密的研究可以合并介绍，最接近本文的工作可用更多篇幅解释差别。

功能示例为“Fu et al. [引用] 通过某种操作处理某个问题，从而改善某项能力”。实际作者和方法必须来自核实的文献，语言和引用格式遵循个人风格文件。

选择对本段论证有用的细节。避免只写方法名、泛泛的性能提升或罗列全部模块。连接句应说明为什么接下来讨论另一个问题或思路，而不只是“此外”“随后”的堆叠。

## 小节结尾

用一句话明确本文在该研究方向中的位置。可以说明目标场景额外需要什么能力，也可以指出有文献依据的适用条件或机制限制。

可参考以下功能句式，但不要让三个小节使用完全相同的结尾。

- 对于某个目标场景，关键不仅在于已有能力，还在于进一步满足某项需求。
- 本文关注的问题更进一步，需要在某种条件下同时实现哪些能力。

三个小节的末句分别回应不同方面，共同支撑论文的问题定义。避免只写“为本文提供了基础”“仍存在不足”或“具有重要意义”，也不要在末句重复完整的方法方案。

没有充分依据时，直接说明本文关注的要求，不把不同研究任务写成已有方法的缺陷。

## 起草与检查

1. 从当前摘要和引言提取任务、目标场景、关键要求和已介绍的文献。
2. 确定各小节的主题范围和最后要落到的具体需求。
3. 为候选文献标明问题、操作、作用及适用条件，按思路组织，去除无关或重复的介绍。
4. 按句子功能起草连续段落，检查每组工作之间的联系是否真实且明确。
5. 核对结尾是否具体、各小节是否分工清楚，以及引文是否支持对应论断。

参考文章用于学习段落功能、递进方式和收束方式。它的任务、假设、方法和结果只有与当前材料一致时才能使用。

只修改用户授权的范围。已有摘要和引言提供论述依据，不因编写相关工作而自动改写这些部分。
